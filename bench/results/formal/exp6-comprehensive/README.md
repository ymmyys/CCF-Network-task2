# exp6 Comprehensive Scenario

Purpose: provide an end-to-end demo combining dynamic capacity, background pressure, fault injection, and recovery.

Key files:

- `exp6-real-comprehensive.csv`
- `exp6-real-comprehensive-metrics.csv`
- `exp6-real-npu4-pressure.csv`
- `exp6-*.state.json` and `exp6-*.metrics.txt`

Formal result: this demo completed 50,003 requests with 7 errors. It is useful for prototype demonstration; the primary quantitative claims come from exp2, exp3, exp4, exp5, and exp7.
